## Slightly fuller version

All R code required to reproduce the simulation analyses reported in this study is available at GitHub ([GITHUB_URL]) and archived as a versioned release in Zenodo ([ZENODO_DOI]). The repository contains the main Simulation-II analysis, True-VC reference analysis, fixed-policy bootstrap and mechanism diagnostics, RL-UP prior-sensitivity analysis, RAM-N matched-replicate analysis, pedigree-structure sensitivity analysis, figure-generation code, and archived-value validation scripts. The definitive production outputs and the final release-wide parse and small self-tests passed the included validation harness.
